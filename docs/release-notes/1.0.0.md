First release in the Nextcloud App Store.

## Features

- Worlds with one click: creative building or a gentle adventure (Luanti).
- Invitations through Nextcloud accounts and groups; player names that are not invited are refused before the login.
- One game password per account, never stored; worlds only receive a verifier.
- Play time per child across all worlds, holidays, time windows per world and a pause for all children from the phone.
- Adult switch: marked adults play without pause and play time rules, never with management rights.
- Manager groups for schools and clubs, set by Nextcloud admins.
- Backups in Nextcloud Files, checked before every restore.
- One Talk room per world with a Gameworld bot, if Talk is installed.
- Setup check in the admin settings with ready-to-copy commands (Docker proxy, network, firewall).
- Up to 8 players per world.
- No telemetry.

## Requirements

- Nextcloud 33 to 35 with AppAPI and a HaRP deploy daemon.
- The scoped docker-socket-proxy in the same Docker network as Gameworld, set up by the admin.
- One UDP port per world (default 30000 to 30019), home network only.

## Privileges

Gameworld controls Docker through the scoped proxy, which is root-equivalent on the host. Details: [docs/privacy.md](https://github.com/street1983nk/nextcloud-gameworld/blob/master/docs/privacy.md)

## Tested installs

- Docker Compose with Nextcloud 34 and 35.0.2
- Nextcloud All-in-One (Nextcloud 34.0.5)

## Languages

- Interface: German, English, French (follows the Nextcloud account language).
- In-game texts per world.

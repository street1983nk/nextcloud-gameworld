frontend/src/i18n/index.js (rein, ohne Vue, ohne Import von @nextcloud/*, damit node frontend/tests/*.check.mjs ohne Browser läuft):
- SUPPORTED_LANGUAGES = ['de', 'en', 'fr'], FALLBACK_LANGUAGE = 'en'
- normalizeLanguage(raw): String vor dem ersten '_' oder '-', klein geschrieben; 'de', 'en', 'fr' bleiben, alles andere (auch leer, null, 'pt_BR', 'de_CH' bleibt 'de') wird 'en'. Beispiele: 'de_DE' -> 'de' (Nextcloud "Deutsch (Sie)" bekommt dieselben du-Texte), 'en_GB' -> 'en', 'fr-CA' -> 'fr', 'es' -> 'en'.
- setLanguage(lang) speichert normalizeLanguage(lang); currentLanguage() liefert sie (Startwert FALLBACK_LANGUAGE).
- t(key, params = {}): Wert aus der aktuellen Sprache, sonst aus 'en', sonst der Schlüssel selbst; Platzhalter {name} werden durch String(params.name) ersetzt, fehlende Parameter bleiben als {name} stehen. Rückgabe ist immer reiner Text (nie HTML).
- tn(key, count, params = {}): wählt key + '.one' oder key + '.other'; de und en: one nur bei count === 1; fr: one bei count 0 und 1. params.count wird automatisch gesetzt.
- compareText(a, b): String(a).localeCompare(String(b), currentLanguage()).
- dateLocale(): 'de-DE' | 'en-GB' | 'fr-FR' für Intl und toLocaleDateString.

Wörterbücher: frontend/src/i18n/<lang>/<bereich>.js mit export default { 'bereich.komponente.name': 'Text', ... } (flaches Objekt, Schlüssel immer mit Bereichspräfix). frontend/src/i18n/<lang>/index.js führt core, parent, admin, kids, world zusammen und wirft beim Import einen Error bei doppeltem Schlüssel. index.js der Laufzeit importiert die drei Sprach-Indizes.

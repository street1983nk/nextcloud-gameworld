I made a Nextcloud app that runs private Luanti worlds for families and schools

Text:

Hi all,

Gameworld is a free app (AGPL) for Nextcloud that runs Luanti worlds on your own server. You create a world with one click, invite players through their Nextcloud accounts, and only invited players get in.

What it does:
- uses the official Luanti 5.17 server image, unmodified
- a small server-side mod checks invites before the login, so random names are refused
- play time limits per child, time windows and holidays (enforced in-game with warnings)
- world backups go to Nextcloud Files
- interface in English, German and French

It is meant for the home network, no public server list. Next step is bigger worlds for school classes, so if you run Luanti with a class or a club, I would love to hear how it goes for you.

Nextcloud App Store: https://apps.nextcloud.com/apps/gameworld
Repo: https://github.com/street1983nk/nextcloud-gameworld

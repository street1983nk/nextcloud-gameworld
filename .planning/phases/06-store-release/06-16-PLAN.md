## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner-Rechner (privater Schlüssel, Token) -> App Store | Signierte Veröffentlichung |
| GitHub-Release-Asset -> jede Installation | AppAPI lädt das Archiv bei jeder Installation neu |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-67 | Information Disclosure | privater Schlüssel, APPSTORE_TOKEN | mitigate | nur Umgebung/Datei beim Owner, nie ausgeben oder committen, Modulus-Vergleich nur per Hash, git log -p geprüft |
| T-06-68 | Tampering | Signatur über falsche Datei (tar.gz nicht reproduzierbar) | mitigate | Signatur über das heruntergeladene Asset, lokale Verifikation gegen das Zertifikat vor dem Upload |
| T-06-69 | Tampering | Tag oder Asset später ersetzt (P-10) | mitigate | Tag endgültig, kein --clobber, Fehler = neue Version |
| T-06-70 | Repudiation | Veröffentlichung ohne Owner-Wort | mitigate | blockierender Entscheidungs-Checkpoint vor Tag und Submit |
| T-06-71 | Spoofing | falsches Zertifikat oder fremde App-ID | mitigate | Zertifikat nur aus nextcloud/app-certificate-requests master, Modulus passt zum Schlüssel; Direktmodus nur für Assets dieses Kontos |

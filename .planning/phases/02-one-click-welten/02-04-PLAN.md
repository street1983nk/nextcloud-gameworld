## Phase Goal

**As a** Elternteil ohne Serverwissen, **I want to** Welten per Klick mit kindgerechtem Preset erstellen, starten, stoppen und ihren Zustand im Dashboard sehen, **so that** meine Kinder sofort spielen können und die Welten ExApp-Updates und Neustarts des Servers überstehen.

<objective>
Vertikaler Slice WELT-02 plus sichtbarer Abschluss von WELT-01: Das Dashboard bietet die Preset-Auswahl, zeigt pro Welt einen verständlichen Status aus Docker (läuft / startet / gestoppt / Fehler) und bietet Neustart. Der Status wird aus docker inspect (State, ExitCode, OOMKilled, StartedAt) und der mtime der Status-Datei des Welt-Mods abgeleitet, nie aus der Datenbank, außer für die Operationszustände creating und failed (RESEARCH Pattern 3, Anti-Pattern 1). Das Dashboard aktualisiert sich alle 5 s bei sichtbarem Tab.

Output: status.py, erweiterter Provisioner (Zustandsfelder, Status-Datei lesen, Retry), restart_world und /restart, neues Dashboard mit Preset-Auswahl, Statuschips, Neustart und Polling.
</objective>

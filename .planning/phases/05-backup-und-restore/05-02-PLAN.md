## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ExApp -> Nextcloud WebDAV | Zugriff im Namen eines Verwalters über AppAPI |
| Nextcloud Files -> ExApp-DB | Dateien in Files sind veränderbar, nur DB-Einträge sind Nachweis |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Information Disclosure | Files-Zugriff | mitigate | jeder Aufruf nc_as(uid) des auslösenden Verwalters, kein geteilter Client, Sessions immer geschlossen (D-01, D-13) |
| T-05-08 | Tampering | Fremde Datei überschrieben (MOVE ohne Overwrite) | mitigate | eindeutiger Zielname per by_path mit Suffix, delete_own nur auf frisch gewählten Namen |
| T-05-09 | Repudiation | Halbe Datei gilt als Sicherung | mitigate | Erfolg nur bei by_path-Größe == lokal; DB-Eintrag erst danach (Plan 05); unvollständige Datei gelöscht (D-11) |
| T-05-10 | Spoofing | Sicherung eines anderen Verwalters nutzen | mitigate | Primärschlüssel (owner_uid, file_id), backup_by_file filtert owner_uid; Test fremder uid ergibt None |
| T-05-11 | Denial of Service | Kontingent voll (507) | mitigate | fester Text MSG_QUOTA, Ziel aufgeräumt |
| T-05-12 | Information Disclosure | Pfade/Namen in Logs | mitigate | nur Fehlertyp und Statuscode loggen |

K3 Limits (vor dem Löschen in K2 prüfen): je Container `docker inspect` HostConfig.Memory == 536870912, MemorySwap == 536870912, PidsLimit == 128, NanoCpus == 1000000000, CapDrop == ["ALL"], SecurityOpt enthält no-new-privileges:true, ReadonlyRootfs true, Privileged false, Config.User == 30000:30000, keine Bind-Mounts (Mounts nur Type volume bzw. tmpfs). Negativkontrolle: ein POST mit `{"name":"x","mem_limit":"8g"}` liefert 422.

K4 Privat per Default: `docker cp <container>:/var/lib/minetest/minetest.conf -` (Tar auf stdout, mit `tar -xO` lesen) enthält `server_announce = false`, `disallow_empty_password = true`, eine Zeile `default_password = ` mit nicht leerem Wert, `default_privs = interact, shout`, keine Zeile `name =`; `tar -tv` zeigt Besitzer root und Modus `-r--r--r--`.
